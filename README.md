A single-line safety warning label for human beings, written in real printed-label wording: "WARNING: This human will press any button marked DO NOT PRESS, then press it twice more just to be sure the warning was serious." The program writes the 128-character label to `entry.txt` — one line, no trailing newline, with a guard that fails loudly if the text ever leaves the 1–160 character gate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
